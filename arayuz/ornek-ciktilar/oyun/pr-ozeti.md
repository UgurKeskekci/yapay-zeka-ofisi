# PR'a hazır dal · ÖRNEK

Örnek Oyun'da dil seçimi kaydı düzeltildi. Bu temsili çıktı gerçek bir kod değişikliği değildir.

- İş: Ana menüde dil seçimi kaydedilmiyor (örnek `ortak/is-listesi.md` maddesi).
- Durum: Örnek senaryoda düzeltildi, patronun incelemesine hazır.
- Ne değişti: Dil tercihi kaydedilip açılışta okunuyor (temsili değişiklik).
- Doğrulama: Kontrol betiği ve hızlı test geçti (temsili sonuç); cihazda denenmeli.
- Dal: `ofis/dil-secimi` (örnek dal).
- PR açma bağlantısı: <oyunlar.json içindeki kod.pr_baglanti kalıbından doldurulur>.
- Süre ve Claude Code tur sayısı: Örnekte ölçülmedi.
